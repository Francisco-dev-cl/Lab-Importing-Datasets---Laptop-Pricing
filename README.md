# Lab: Importing Datasets - Laptop Pricing

This repository contains a targeted data analytics laboratory project focused on the foundational stages of the Data Science lifecycle: data ingestion, structured layout adjustment, and database parsing utilizing commercial hardware datasets.

## 🎯 Project Objective

The goal of this lab is to practice the fundamentals of exploratory data preparation. The project walks through loading raw unformatted data streams, defining custom relational column labels, auditing index types, evaluating structured missing values, and mapping complex attributes (such as screen size, CPU details, and storage parameters) to optimize downstream feature engineering and regression tracking.

## 📁 Repository Structure

* **`Practice_data_loading.ipynb`**: The primary interactive Jupyter Notebook outlining the program execution flow for multi-source data loading, string transformation, data-type casting, and table serialization using Pandas.
* **`laptops.csv`**: The primary comma-separated text file housing technical specifications, hardware attributes, and consumer market prices for various laptop configurations.

## 🛠 Technologies Used

* **Language:** Python 3.x
* **Core Environment:** Jupyter Notebooks
* **Data Engineering Libraries:** Pandas, NumPy

## 🚀 Installation and Execution

### Local Environment Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Lab-Importing-Datasets---Laptop-Pricing
   ```

2. **Install required analytics packages:**
   Ensure your Python deployment environment includes core scientific processing blocks:
   ```bash
   pip install pandas notebook
   ```

3. **Launch the development environment:**
   ```bash
   jupyter notebook
   ```

4. **Run the data pipeline:**
   Open `Practice_data_loading.ipynb` inside the Jupyter dashboard workspace and execute the code blocks from top to bottom.

## 📈 Demonstrated Skills

* **Data Engineering Fundamentals:** Programmatically loading unmapped, complex matrices into memory while managing variable column parameters and custom character encoding profiles.
* **Structural Feature Profiling:** Auditing tabular object signatures to perform explicit data-type casting (e.g., transforming text categories into descriptive numerical markers).
* **Deterministic Data Extraction:** Slicing raw data blocks using advanced matrix functions to build clean, predictable tables optimized for statistical feature matching.
